# הקמה למדריך: AI for Developers

תיקייה זו מכילה את כל מה שצריך להכין **לפני** ההדרכה למפתחים. בצעו לפי הסדר.

| קובץ | מה זה | מתי |
|------|-------|-----|
| `github-setup.md` | יצירת repo ב-GitHub ודחיפת `findash/` אליו | לפני השיעור |
| `azure-devops-setup.md` | יצירת ה-Work Item לפיצ'ר | לפני השיעור |
| `feature-spec.md` | הטקסט המלא של דרישת הפיצ'ר (מקור ל-Work Item) | חומר עזר |
| `push-to-github.ps1` | סקריפט עזר (PowerShell) לדחיפה מהירה ל-GitHub | אופציונלי |
| `INSTRUCTOR-NOTES.md` | **סודי** - מיקום הבאגים, פתרונות, ערכי אימות | למדריך בלבד |

## סדר פעולות מומלץ

1. הריצו וידוא מקומי של האפליקציה (ראו `../../findash/README.md`).
2. בצעו את `github-setup.md` - העלו את הקוד ל-GitHub (אם עדיין לא ב-public).
3. בצעו את `azure-devops-setup.md` - צרו את ה-Work Item.
4. אספו את שני הקישורים (repo + Work Item) לשיתוף עם המשתתפים.

## אזהרה

- **אל תדחפו את `INSTRUCTOR-NOTES.md` ל-repo של המשתתפים** - הוא מכיל את פתרון הבאגים והפיצ'ר.
- דחפו רק את תוכן `findash/` ל-GitHub (ראו `github-setup.md`).
- ערכת הלומדים: `../../ai-for-developers-learners/` (בלי תיקייה זו).

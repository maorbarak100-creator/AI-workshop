# מפרט פיצ'ר - "סיכום חודשי הכנסות מול הוצאות"

זהו הטקסט שממנו בונים את ה-Work Item ב-Azure DevOps (ראו `azure-devops-setup.md` בתיקייה זו).
המשתתפים ימשכו את הדרישה מ-Azure DevOps ויממשו אותה עם agent בתרגיל 2.

---

## כותרת (Title)
הוספת סיכום חודשי של הכנסות מול הוצאות למסך החשבון

## סוג (Work Item Type)
User Story / Product Backlog Item

## תיאור (Description)

בתור **לקוח שמנהל את חשבונו ב-FinDash**,
אני רוצה **לראות סיכום חודשי של הכנסות מול הוצאות עבור חשבון**,
כדי **להבין את דפוסי ההוצאה שלי ולנהל תקציב טוב יותר**.

כיום מסך החשבון מציג את היתרה הנוכחית ורשימת תנועות, אך אין תמונה מצטברת לפי חודש. יש להוסיף חלוקה חודשית שמסכמת בנפרד את סך ההפקדות (הכנסות) ואת סך המשיכות (הוצאות) בכל חודש, ולהציג אותה בממשק.

## תנאי קבלה (Acceptance Criteria)

1. **Backend:** קיים endpoint חדש `GET /api/accounts/:id/summary` שמחזיר, לכל חודש שבו יש תנועות, אובייקט עם: `month` (בפורמט `YYYY-MM`), `income` (סך ההפקדות), `expense` (סך המשיכות).
2. התוצאה מסודרת מהחודש המוקדם לחדש ביותר.
3. עבור מזהה חשבון שאינו קיים - מוחזר סטטוס `404`.
4. **Frontend:** במסך פרטי החשבון מוצג בלוק "סיכום חודשי" שמציג לכל חודש את ההכנסות מול ההוצאות בצורה ויזואלית (טבלה או תרשים עמודות פשוט).
5. הסכומים מוצגים במטבע של החשבון ובפורמט מספרי קריא.
6. כאשר אין תנועות בחשבון - מוצגת הודעה מתאימה ולא שגיאה.

## הערות טכניות (לא מחייבות)
- אפשר להשתמש בשדה `date` הקיים בכל תנועה (פורמט `YYYY-MM-DD`) לחילוץ החודש.
- אין חובה להוסיף ספריית גרפים - תרשים עמודות פשוט מבוסס CSS מספיק.
- כדאי להוסיף טסט ל-Backend שמאמת את חישוב הסיכום.

## דוגמת פלט צפויה (Backend, עבור acc-1001)
```json
{
  "accountId": "acc-1001",
  "currency": "ILS",
  "months": [
    { "month": "2026-01", "income": 8000, "expense": 1550 },
    { "month": "2026-02", "income": 8000, "expense": 1700 },
    { "month": "2026-03", "income": 8000, "expense": 1200 }
  ]
}
```

## הגדרת "בוצע" (Definition of Done)
- הקוד עובד מקומית (Backend + Frontend), ונבדק ידנית מול לפחות חשבון אחד.
- כל תנאי הקבלה מתקיימים.
- נכתב טסט אחד לפחות ל-Backend.
- הקוד נדחף ל-branch ונפתח Pull Request (אופציונלי, לפי סביבת הארגון).

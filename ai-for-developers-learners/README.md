# ערכת הדרכה למשתתפים: פיתוח עם AI Agents ב-Cursor

זהו ה-repo להתחלה. פתחו את התיקייה ב-Cursor, ופתחו את `playbook.html` בדפדפן.

כל התרגילים בערכת זו רצים **באותו יום**: קודם תרגיל 1 (חימום), אחר כך תרגיל 2 (FinDash).

---

## מבנה הערכה

| קובץ / תיקייה | תיאור |
|---------------|-------|
| `playbook.html` | מדריך התרגילים (תרגיל 1 + תרגיל 2). פתחו בדפדפן. |
| `sample-code/` | קוד דמו לתרגיל 1 (`finance-utils.js`) |
| `AGENTS.md` | הנחיות קצרות ל-agent כשתיקייה זו היא ה-workspace |

---

## איך מתחילים

1. שכפלו (clone) את ה-repo הזה, או הורידו ZIP וחלצו.
2. פתחו את התיקייה ב-Cursor (**Open Folder**).
3. פתחו את `playbook.html` בדפדפן ועקבו אחרי **תרגיל 1** (כולל `sample-code/`).
4. ל**תרגיל 2**: שכפלו את repo **FinDash** הנפרד (קישור מהמדריך), ופתחו אותו ב-Cursor לפי ההוראות בפלייבוק.

---
